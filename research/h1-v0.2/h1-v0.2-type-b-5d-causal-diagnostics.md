# H1 v0.2 — Type B: причинные диагностики Ning et al. и их 5D обобщение

## Резюме

Статья Ning et al. задаёт **4D** сферическую систему Einstein–скаляр–радиационная жидкость и начинает эволюцию с конечного ложновакуумного домена (FVD) и гладкой стенки, уже присутствующих в начальных данных. Для выбранных параметров авторы сообщают Type B: внутренний areal radius растёт, появляется внешний минимум areal radius, при (t=162.125) одновременно обращаются в ноль обе null-expansion, затем расходятся apparent- и anti-trapped marginal branches. По их описанию throat radius позднее уменьшается до нуля; авторы интерпретируют это как сингулярность и pinching-off. Это результаты конкретной конечновременной 4D симуляции, а не вывод о геодезически полном, топологически новом manifold.

В сферической симметрии без выбора координат корректно переносимы на 5D: areal radius (R), null expansions (	heta_pm), их знаковая классификация и инвариант (chi=h^{ab}\nabla_aR\nabla_bR). **Не переносимы автоматически** 4D формула (2GM/R=1), численные Type A/B пороги, начальные данные, потенциал, наличие Type B, геодезическая полнота или родительско-дочерние часы.

Для исходного регулярного 5D семейства тест регулярных начальных данных при (QL^2<1) вывод остаётся прежним: начальный срез time-symmetric и не содержит trapped/anti-trapped круглых (S^3). Его будущая эволюция не вычислена. Type B в статье не предсказывает, произойдёт ли такой исход в тест регулярных начальных данных.

Статусы в тексте: **SOURCE_DERIVED** — прямо задано/сообщено источником; **MATHEMATICALLY_DERIVED** — выведено здесь из указанных определений; **CONDITIONAL** — вывод при явных предпосылках; **NOT_DERIVED** — данных для вывода нет.

## 2. Что именно рассчитывается в 4D статье

### 2.1 Метрика, переменные и часы

В §2.1 приняты (c=G=1), signature ((-+++)), spherical metric (Eq. 2)

\[
ds^2=-A(t,r)^2dt^2+B(t,r)^2dr^2+R(t,r)^2d\Omega_2^2.
\]

Определены (U=D_tR=\dot R/A), (\Gamma=D_rR=R'/B), а trace extrinsic curvature — Eq. (4), с конвенцией (K_{ij}=-\mathcal L_n\gamma_{ij}/2). Источник задаёт canonical scalar и radiation perfect fluid; (p=\rho/3), и по принятому допущению их stress tensors отдельно сохраняются, взаимодействуя друг с другом гравитационно. Потенциал Eq. (9) феноменологический, температурно-независимый: φ=0 — false vacuum, φ=φT — true vacuum; λ управляет барьером.

Для эволюции авторы выбирают geodesic slicing (A=1), shift равен нулю. Поэтому координатный (t) есть proper time нормальных наблюдателей с постоянными пространственными координатами в этой slicing. Это **не** означает, что (t) — proper time движущейся wall, отдельные parent-clock (T_P) или физически определённое daughter FLRW time (t_D). Собственное время движущейся worldline следует из pullback метрики; отдельного parent–daughter event map статья не задаёт.

Уравнения эволюции Eqs. (18a–i) включают геометрию, скаляр и fluid. В частности,

\[
\dot R=U,\qquad
\dot U=-\frac{1+U^2-\Gamma^2}{2R}-4\pi R T^1{}_1,
\]

а для скаляра Π=ẋφ и

\[
\dot\phi=\Pi,\qquad
\dot\Pi=K\Pi+\frac{1}{BR^2}\left(\frac{R^2}{B}\phi'\right)'-\partial_\phi V.
\]

Это примеры из полной авторской системы, не переопределение её equations.

### 2.2 Начальный домен и граничные условия

В §2.2 начальный срез — super-horizon FVD в radiation-dominated flat-FLRW background. После безразмерного масштабирования (H_i=1), (a_i=1), авторы задают (B=1, R=r, U=r, \Gamma=1, K=-3) (Eq. 20), профиль стенки (Eq. 21)

\[
\phi_i(r)=\frac{\phi_T}{2}\left[1+\tanh\!\left(\frac{r-r_i}{l}\right)\right],\qquad l=r_i/10,
\]

и Π=0, (v=0). Ради radiation-компенсируется по Eq. (23), чтобы начальная суммарная плотность была однородной. Значит, задача **не начинается с featureless vacuum**: FVD, фазовый профиль и wall energy уже заложены в исходный срез. Эволюция показывает судьбу подготовленного неоднородного seed.

В центре задаются условия регулярности. На внешней границе (r_{max}=5r_i) поле закреплено в true vacuum, чтобы сохранять внешний FLRW-like фон. Это конкретная симметричная конечнодоменная задача, а не полный глобальный construction будущего бесконечного пространства-времени.

## 3. Точная 4D диагностика Type A, Type B и dispersal

### 3.1 Null normals и expansions статьи

В §2.4 авторы задают ковариантные компоненты радиальных null-векторов (Eq. 27)

\[
k_\mu^\pm=\frac{1}{\sqrt2}(-A,\ \pm B,0,0),\qquad k^+\!\cdot k^-=-1.
\]

Их raising index даёт будущие направленные (k_\pm^\mu=(1/(\sqrt2A),\ \pm1/(\sqrt2B),0,0)) при (A,B>0). Для сфер площадью (4\pi R^2) определение (28) приводит к Eq. (29):

\[
\Theta^\pm=\frac{\sqrt2}{R}(U\pm\Gamma).
\]

Отсюда следуют классификации статьи:

| Θ+ | Θ− | Классификация в нормировке статьи |
|---:|---:|---|
| (>0) | (<0) | нормальная сфера |
| (<0) | (<0) | future-trapped |
| (>0) | (>0) | anti-trapped |
| (0) | (<0) | marginally trapped / apparent horizon, Type A diagnostic |
| (>0) | (0) | marginally anti-trapped branch |
| (0) | (0) | bifurcating trapping horizon, Type B diagnostic авторов |

Условие simultaneous zero означает (U=0) и Γ=0 в этой точке. После разделения branch с Θ+=0,Θ−<0 имеет (U=-\Gamma), а branch с Θ−=0,Θ+>0 — (U=\Gamma>0). То есть авторское Type B picture содержит соседние collapsing/trapped и expanding/anti-trapped marginal branches. Для экспансии внутреннего patch статья также непосредственно отслеживает (R(t,r)): при фиксированном comoving (r) внутри FVD (U=\dot R>0) соответствует росту ареального радиуса; это геометрическое утверждение в выбранной threading, не независимая глобальная дочерняя метрика.

### 3.2 Масса, локальный горизонт и 4D условие

Misner–Sharp mass (Eqs. 24–25):

\[
M_{MS}=\frac R2(1-g^{\mu\nu}\partial_\mu R\partial_\nu R)
=\frac R2(1+U^2-\Gamma^2),
\]

в (G=1). Производная по (r) (Eq. 26) связана с комбинацией constraints:

\[
M'_{MS}=4\pi R^2(R'T_{00}-\dot R T_{01}).
\]

Из Eqs. (25),(29) следует Eq. (32):

\[
\Theta^+\Theta^- = \frac{2}{R^2}(U^2-\Gamma^2),\qquad
\Theta^+\Theta^-=0\iff \frac{2M_{MS}}R=1.
\]

Последнее эквивалентно (2GM_{phys}/(c^2R)=1) при восстановленных единицах. Это критерий marginal spherical surface в этой **4D Einstein** модели. Само равенство (2M/R=1) не классифицирует поверхность как trapped или anti-trapped: нужны отдельные знаки обоих expansions.

### 3.3 Опубликованная временная последовательность

Для representative Type B, φT=0.1, λ=20, (r_i=10), (V_F=5\times10^{-5}), рисунок 2 и §3.1 сообщают:

1. Начальная FLRW slicing имеет (t_i=\alpha=1/2); скалярный FVD уже присутствует. На старте домен быстро сжимается из-за разности давлений вакуумов.
2. Внутри FVD начинается inflation-like evolution: (R(t,r)) растёт приблизительно экспоненциально для внутреннего профиля; у wall возникает локальный максимум (R(r)), снаружи — локальный минимум, который авторы называют wormhole throat.
3. При (t=162.125) авторы отмечают Θ+=Θ−=0 у throat — bifurcating trapping horizon.
4. Затем одна marginal branch удовлетворяет Θ+=0,Θ−<0 (apparent horizon), другая — Θ−=0,Θ+>0 (anti-trapped branch); ветви расходятся в противоположных направлениях.
5. По тексту после бифуркации areal radius throat уменьшается и достигает нуля; авторы интерпретируют это как образование сингулярности и pinching-off от внешней области.

Пункт 5 важен: опубликованный Type B не является показанной вечной регулярной daughter-cosmology. Нулевой areal radius — авторская численная интерпретация сингулярного исхода; настоящая записка не доказывает, что это curvature blow-up, а не ограничение разрешения/координат, потому что независимые инварианты у этого конечного события здесь не пересчитывались. Но он определённо не даёт основания утверждать доказанную геодезически полную дочернюю Вселенную.

Type A при (V_F=10^{-5}): обычная marginal apparent horizon Θ+=0,Θ−<0 после доминирования коллапса; авторы приводят ориентировочно (t\sim50) для horizon crossing в representative case. Dispersal при (V_F=5\times10^{-7}): в исследованной эволюции домен рассеивается и trapped surfaces не появляются.

### 3.4 (t_H/t_V) — предиктор, не теорема и не время рождения

В §4, для radiation-dominated FLRW estimate (H=1/(2t)), физический радиус FVD (a(t)r_i) при пренебрежении возмущениями даёт Eq. (33):

\[
t_H=\frac{r_i^2}{4t_i}.
\]

Это background estimate времени, когда размер initial FVD пересекает Hubble scale. (t_V\equiv\tfrac12\sqrt{3/(8\pi\rho_V)}) (Eq. 34) — выбранная оценка времени, когда вакуумная плотность начинает доминировать над локальной динамикой; (t_\sigma=1/(2\pi\sigma)) (Eq. 35) — wall-tension scale. Все используются после нормировки (H_i=1), значит это **безразмерные модельные времена** до восстановления исходной размерной шкалы. Они не являются собственным временем shell, parent observer или daughter FLRW.

Авторы подчёркивают: (t_H/t_V\gtrsim1) — heuristic: vacuum domination успевает предшествовать/сопутствовать horizon crossing; тип исхода подтверждается только дальнейшей эволюцией и фактической horizon диагностиками. Bisection survey даёт Type B примерно (1.1–1.6) (приближение к thin-wall estimate ∼1.25 при росте λ); Type A примерно (0.35–0.7). Эти интервалы относятся к исследованным профилям/параметрам (φT,λ,(r_i)) и не являются универсальными необходимыми или достаточными условиями.

## 4. Независимый вывод в (D) измерениях

Пусть (D\ge4), пространство-время сферически симметрично и локально имеет warped-product вид

\[
ds_D^2=h_{ab}(x)dx^a dx^b+R(x)^2d\Omega_{D-2}^2,
\]

где (h_{ab}) — лоренцева метрика двумерного orbit space, (R>0) — геометрический areal radius. Площадь round orbit:

\[
\mathcal A_{D-2}=\Omega_{D-2}R^{D-2}.
\]

Возьмём будущие радиальные нулевые векторы (k_\pm^a) и зафиксируем нормировку (k_+\cdot k_-=-1). Тогда

\[
\theta_\pm=\frac1{\mathcal A_{D-2}}\mathcal L_{k_\pm}\mathcal A_{D-2}
=\frac{D-2}{R}k_\pm^a\nabla_aR.
\]

Положительное boost-перемасштабирование (k_+\to e^f k_+, k_-\to e^{-f}k_-) сохраняет cross-normalization, умножает каждую θ на положительный фактор и потому сохраняет знак/нулевой статус, но не величину. Независимое положительное масштабирование также сохраняет знаки. Чтобы видеть коэффициент явно, пусть (u^a) — future unit timelike, (s^a) — outward unit spacelike, (u^2=-1,s^2=+1,u\cdot s=0), и (k_\pm=(u\pm s)/\sqrt2). Обозначая (U=u(R),\Gamma=s(R)), получаем

\[
\theta_\pm=\frac{D-2}{\sqrt2R}(U\pm\Gamma),\qquad
\chi\equiv h^{ab}\nabla_aR\nabla_bR=-U^2+\Gamma^2,
\]

\[
\theta_+\theta_-=-\frac{(D-2)^2}{2R^2}\chi.
\]

Коэффициент справа зависит от выбранной нормировки null normals; χ и нулевое условие — нет. Для альтернативной нормировки из тест регулярных начальных данных (k_\pm=u\pm s), cross product −2, получаем θ±=(D−2)(U±Γ)/R и произведение −(D−2)²χ/R².

### 4.1 4D специализация

Для (D=4), (\Omega_2=4\pi), cross-normalized basis даёт

\[
\theta_\pm=\frac{2}{\sqrt2R}(U\pm\Gamma)=\frac{\sqrt2}{R}(U\pm\Gamma),
\qquad \theta_+\theta_-=-\frac{2\chi}{R^2}.
\]

Это в точности формула Ning et al. (29), где (U=\dot R/A, Gamma=R'/B). На нормальной ветви при ориентированном outward radial coordinate (\Gamma>0): Type A apparent branch имеет (U=-\Gamma<0), а marginal anti-trapped branch Type B имеет (U=\Gamma>0). На самих marginal spheres одна экспансия нулевая; обе одновременно нулевые только в точке (U=\Gamma=0). Знак θ± на всех соседних сферических срезах всё равно надо вычислять, а не выводить из произведения.

### 4.2 5D специализация и масса

Для (D=5), (\Omega_3=2\pi^2):

\[
\theta_\pm=\frac{3}{\sqrt2R}(U\pm\Gamma),\qquad
\theta_+\theta_-=-\frac{9\chi}{2R^2}.
\]

При (\chi<0) произведение положительно: round (S^3) может быть future-trapped **или** anti-trapped; чтобы различить их, нужны отдельные знаки и будущее направление обоих векторов. При χ=0 сфера marginal. Условие χ=0 — локальный геометрический критерий, не название глобального event horizon.

В 5D Einstein gravity без Λ определим физическую generalized Misner–Sharp mass

\[
M_{MS}^{(D)}=\frac{(D-2)\Omega_{D-2}}{16\pi G_D}R^{D-3}(1-\chi).
\]

Размерность (G_D=L^{D-2}) при (c=1), поэтому (M_{MS}sim L^{-1}), как физическая энергия. В 4D это (M=R(1-\chi)/(2G_4)); при (G_4=1) совпадает с Eq. (24) Ning et al. В 5D:

\[
M_{MS}^{(5)}=\frac{3\,(2\pi^2)}{16\pi G_5}R^2(1-\chi)
=\frac{3\pi}{8G_5}R^2(1-\chi).
\]

В асимптотически плоском Tangherlini vacuum (\chi=f=1-\mu/R^2), поэтому

\[
\mu=\frac{8G_5M}{3\pi},\qquad
\chi=1-\frac{8G_5M}{3\pi R^2},\qquad
\chi=0\iff R^2=\frac{8G_5M}{3\pi}.
\]

Следовательно, замена (2GM/R=1) на 5D критерий делается **через** (R^{-2}) и точный коэффициент (8/(3\pi)), а не переносом 4D порога.

При Λ или постоянном вакуумном (V) надо заранее выбрать, включается ли соответствующая плотность в quasi-local mass. Для Schwarzschild-(A)dS конвенции (f=1-\mu/R^{D-3}-2\Lambda_{eff}R^2/[(D-1)(D-2)]) можно определить background-subtracted mass с множителем

\[
1-\chi-\frac{2\Lambda_{eff}R^2}{(D-1)(D-2)}.
\]

Нельзя одновременно учитывать постоянное (V) как источник в (T_{ab}) и второй раз включать его как отдельную Λ без соответствующего вычитания. Для переменного scalar/radiation source масса меняется по flux/evolution; vacuum Tangherlini expression не является постоянной массой внутри вещества.

## 5. Raychaudhuri, NEC и ограничения на переход ветвей

Для hypersurface-orthogonal null congruence с аффинным параметром λ в (D) измерениях:

\[
\frac{d\theta}{d\lambda}
=-\frac{\theta^2}{D-2}-\sigma_{ab}\sigma^{ab}-R_{ab}k^ak^b.
\]

В Einstein gravity (R_{ab}k^ak^b=8\pi G_D T_{ab}k^ak^b) для null (k^a) (члены, пропорциональные метрике, сокращаются). Для canonical scalar

\[
T_{ab}k^ak^b=(k^a\nabla_a\phi)^2\ge0,
\]

а для perfect fluid это (T_{ab}k^ak^b=(\rho+p)(u\cdot k)^2\ge0), если ρ+p≥0. Значит при NEC null convergence производная не положительна; при θ=0 она равна −σ²−Rkk≤0. Это restricted lemma для одной и той же гладкой hypersurface-orthogonal null congruence с будущей affine orientation.

**Следствие:** вдоль такого же null генератора регулярная эволюция от θ<0 к θ>0 невозможна при NEC: θ монотонно не возрастает. Переход от θ>0 к θ<0 возможен и соответствует focusing. Это не общий запрет на baby universe: сравнение expansions на разных сферических поверхностях/разных генераторах не является эволюцией одной θ вдоль одного генератора. В сферической геометрии соседние поверхности могут менять Γ=s(R), а ориентированная внутренняя область за throat иметь другой пространственный radial direction. Поэтому локальная анти-трэппированность или рост (R) внутри throat может сосуществовать с NEC; это не говорит, как область глобально возникла или продолжилась.

Для Type B bifurcation необходимо не просто «сменить знак θ»: при одновременном нуле оба radial null derivative (k_\pm(R)) равны нулю, затем разные marginal branches имеют указанные выше знаки. Никакая из двух маргинальных ветвей отдельно не доказывает нарушения NEC. Но если утверждать, что вдоль одного и того же future null congruence expansion прошла от отрицательной к положительной без caustic/обрыва, нужно либо показать ошибку идентификации congruence, либо пересмотреть NEC/null convergence, regularity или гипотезы теоремы.

Статья B использует canonical scalar и радиацию с ρ+p>0, то есть её гладкие вещества удовлетворяют NEC. Это совместимо с локальным formation/separation trapping branches; в конечном Type B описании сами авторы сообщают достижение throat (R\to0) и сингулярный pinching-off. В тест регулярных начальных данных canonical massless scalar также удовлетворяет 5D NEC, однако (QL^2<1) гарантирует только отсутствие начальных trapped/anti-trapped round (S^3). Ни в одном случае одно лишь NEC не позволяет определить весь сценарий без полной геометрии/эволюции.

Raychaudhuri плюс compact future-trapped surface может дать null geodesic incompleteness лишь при полном наборе глобальных предпосылок подходящей Penrose-type теоремы (в частности, global hyperbolicity и noncompact Cauchy surface). Ни локальная apparent/trapping horizon, ни finite computational region не устанавливают сами эти предпосылки. Incompleteness также не тождественна автоматически доказанному curvature blow-up или конкретному maximal extension.

Статья B потенциально пригодна как 4D физический контроль для выбора **вопросов и diagnostics**, не как пороговый рецепт для тест регулярных начальных данных. тест регулярных начальных данных содержит ровно другой source set: 5D Einstein + massless canonical scalar, Λ5=0, с конформно-плоской time-symmetric (R^4) начальной геометрией. При (QL^2<1) авторская/локальная аналитика даёт (dR/d\ell>0), (\theta_\pm=\pm3(dR/d\ell)/R) в нормировке (k_\pm=u\pm s). Будущего интегрирования нет; нет ложного вакуума, radiation bath или сформированного FVD. Совпадение критерия χ=0 или похожей формы графика horizon не является свидетельством Type B в 5D.

Одна проверка из точных тест регулярных начальных данных определений: (R(r)=r\psi(r)), (d\ell=\psi dr), (\psi'=-I/r^3). Поэтому

\[
\frac{dR}{d\ell}=\frac{1}{\psi}\frac{d(r\psi)}{dr}
=1+\frac{r\psi'}{\psi}=1-\frac{I(r)}{r^2\psi(r)},\qquad
\theta_\pm=\pm\frac{3}{R}\left(1-\frac{I(r)}{r^2\psi(r)}\right)
\]

для выбранной в тест регулярных начальных данных нормировки (k_\pm=u\pm s), где (u(R)=0) на time-symmetric срезе. Условие (QL^2<1) в тест регулярных начальных данных гарантирует положительность скобки для указанного профиля. Значит начальные знаки — нормальная пара (+,−), а не Type B; это не ограничивает знаки на будущем срезе без решения эволюции.

## 7. Диагностическая спецификация для будущего solver_H1 (не реализация)

Любой будущий 5D spherical solver, который проверяет Type B-like признаки, должен сообщать как минимум:

1. **Геометрия и уравнения:** (D=5), (h_{ab}), (R), signature, action/stress tensor, Λ и mass convention; constraints и эволюционные PDE независимы от нарисованной интерпретации.
2. **Локальные expansions:** явно заданные future/outward null vectors, их normalization, (U,\Gamma,\chi), обе θ± на каждой поверхности; trapped/anti-trapped/marginal labels по двум знакам, не по одному mass ratio.
3. **Horizon history:** worldtubes θ+=0 и θ−=0, условия их возможной бифуркации θ+=θ−=0, характер/пересечение/исчезновение; отдельно coordinate slicing и инвариантные величины. Нулевые expansion поверхности invariant к положительной перенормировке null normals, но apparent/trapping-horizon *worldtube и его временная локализация* зависят от фолиации; event horizon глобален.
4. **Масса:** именно 5D (M_{MS}) или явно выбранная Λ-subtracted mass; размерностная сверка и независимая проверка relation к χ. Запрещено ставить 4D (2GM/R) порог.
5. **Regularity и constraints:** центр/асимптотика/границы; нормированные Hamiltonian и momentum residuals, scalar/fluid conservation, resolution/CFL convergence, mass-flux ledger и gauge stop. Вычисление горизонта не компенсирует constraint failure.
6. **Часы и причинность:** (T_P), τ переходной worldline, (t_D) — отдельные часы с точными worldlines и метриками. Сопоставлять события только при физически указанной causal path/mediator. Null ray tracing по вычисленной области и явно ограниченная область будущего; фиксировать, доступны ли parent observers или infinity.

Матрица достаточности:

| Заявление | Минимально необходимое свидетельство | Чего недостаточно |
|---|---|---|
| (a) Внутренний расширяющийся patch | (R>0), регулярные invariants, (u(R)>0) для указанной timelike congruence на интервале; источник и constraints сходятся | Рост поля/радиуса на одной координатной картинке |
| (b) Bifurcating trapping horizon | Обе future radial expansions одновременно равны нулю в одном корректно нормированном событии; после него отдельно проверены marginal branches и их знаки | Только (M/R) threshold или пересечение графиков без sign table |
| (c) Регулярное дочернее космологическое время | Определённая daughter worldvolume/FLRW congruence, ненулевая невырожденная метрика и собственное (t_D) на продолжающемся регулярном участке | Geodesic-slicing (t), wall coordinate или finite local expansion |
| (d) Геодезическая полнота и глобальная отдельность | Максимальное/достаточное глобальное продолжение, causal domains (J^\pm), указанные parent observers/infinity, доступность сигналов, полнота или явно доказанное причинное разделение | Apparent horizon, throat snapshot, anti-trapped sphere, finite simulation endpoint |
| (e) Сохранение/связь parent exterior | Внешняя область/заряд/flux вычислены в полном источнике и matching; причинный канал объяснён | Предположение о сохранении внешней массы или чужой 4D теоремы Birkhoff |

### Явные критерии отказа от сильных заявлений

- Любой неустойчивый/несходящийся constraint или unresolved (R\to0) endpoint: **не утверждать** достоверное horizon/pocket beyond validated domain.
- Нет одновременного нуля θ±: не классифицировать событие как bifurcating Type B по определению этой статьи.
- Есть только χ=0 без двух sign diagnostics: сообщать marginal sphere, не называть trapped/anti-trapped.
- Невозможно определить daughter timelike congruence/event map: (t_D), (T_P) и (dt_D/dT_P) помечать **NOT_COMPARABLE / NOT_DERIVED**.
- Нет глобального continuation и causal reachability: не утверждать геодезически полную новую Вселенную/смену топологии.

Эти критерии качественные и логические; численные thresholds не придуманы. H2 dark matter остаётся отдельным вопросом, повторные рождения не являются аксиомой, универсальный clock map не вводится.

## 9. Ровно один следующий теоретический шаг

**Сформулировать минимальный 5D action/source-set тест: определить, какой потенциал/радиационный сектор, асимптотика и regular initial-data mechanism нужны, чтобы вообще задать в 5D аналог compensated pre-existing FVD, и вывести только его constraints, NEC и marginal-sphere condition.** Проверка завершается до эволюционных чисел: либо initial-data constraints допускают заявленный профиль без pre-imposed daughter topology, либо выявляется точно сформулированное ограничение этой family. Не запускать solver и не использовать 4D (t_H/t_V) как 5D threshold. Даже положительный ответ будет лишь подготовленной 5D задачей Коши, не доказательством Type B или рождения daughter.
