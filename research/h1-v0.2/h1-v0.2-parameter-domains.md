# H1 v0.2 — словарь параметров и условные области допустимости

Документ не подбирает параметры и не объединяет несовместимые действия. «Область» ниже означает либо строгое алгебраическое условие конкретной модели, либо явно помеченный toy-диапазон; она не является областью, уже допустимой для H1 в целом.

## Словарь параметров

| Символ | Значение / единицы | Локальное использование и статус |
|---|---|---|
| `κ=8πG` | В natural units `[κ]=L²` при массовой размерности поля; в коде используется размерностно-нормированное `κ` | #39–#41 scalar toy используют `κ=.1` как безразмерный параметр после `μ`-нормировки, не измеренную физическую `G`. |
| `H0` | `[T⁻¹]`; в FLRW baseline `.0716 Gyr⁻¹` | #31/#32 именно toy/reference normalization. |
| `a_D` | dimensionless FLRW scale factor, нормировано `a_D(today)=1` | Только для однородной дочерней модели #31/#32. Радиальный coefficient `a(r,t)=1/√f` в #40 — другое обозначение и не `a_D`. |
| `Ωr, Ωm, ΩΛ, Ωk` | dimensionless; `Ωk=1−Ωr−Ωm−ΩΛ` в adopted normalization | В обычной FLRW постановке доли компонентов; их значения в #31 — reference inputs, закрытые варианты #32 — иллюстративные. |
| `K0,n` | `K0` в единицах `[time_D]/[time_P]` для `dt_D/dT_P=K0 a_D^n`; `n` dimensionless | `K0=10⁹ daughter yr / parent s` — условная нормировка, не калиброванная по физическому родителю. Никакой разрешённый универсальный диапазон не получен. |
| `Hv` | `[T⁻¹]`; shell-примере `.0716 Gyr⁻¹` | В #33 отдельная dS Hubble scale. Это не автоматически FLRW `H(a)` из #32. |
| `M_g=GM` | геометрическая длина в `c=G=1` | Schwarzschild bulk; физическая масса в kg требует отдельного выбора `G,c` и конверсии. |
| `σ` | surface energy density/tension; `α=4πGσ` имеет `[L⁻¹]` | #33 постоянная положительная wall tension; `s=α/Hv` dimensionless. Не равна объёмной плотности скаляра из #40. |
| `m=GM Hv`, `x=HvR`, `s=α/Hv` | dimensionless | Параметры #33 shell potential. `W=Rdot²` также dimensionless в `τ` scaled by `Hv⁻¹`; `W<0` область запрещена. |
| `λ,δ,φ` (#39–40) | Dimensionless после выбора `μ` и `M_Pl` scaling | `V=λφ²(φ−1)²/4+δ(3φ²−2φ³)`; истинный AF вакуум `φ=0,V=0`, локальный false vacuum `φ=1,V=δ` при `λ>0,0<δ<λ/12`. Это только локальная scalar model. Не путать `λ` с #38 interpolation lambda. |
| `A,R0,κ` (#39–41) | Dimensionless profile amplitude/radius/coupling в `μ`-единицах | Gaussian-like smooth lump — заданная начальная затравка, а не spontaneous seed-free creation. Использованные сеточные ряды — numerical test matrix, не physical bounds. |
| `α_ref, β, r, q=Q/m_ref` (#38) | Dimensionless | Toy coupling/running inputs. Sharp threshold formula — иллюстрация, не exact QED RG calculation. |
| `μ t`, `u,v`, `τ_B`, `T_P`, `t_D` | Разные координатные/собственные времена | Без физического mapping между мировыми линиями численно отождествлять запрещено. См. [математический реестр](h1-v0.2-mathematical-registry.md), запись R-020. |

## Условия, следующие из конкретных уравнений

| Условие | Следствие в названной модели | Статус эмпирики/проверки |
|---|---|---|
| FLRW admissibility: `F(a)=H²(a)≥0`, `a>0` | `F<0` участок не принадлежит вещественной классической FLRW-ветви. Начальный знак `H=±√F` задаёт expanding/contracting branch; у корня `Hdot=(a/2)F'` определяет bounce (`>0`) или turnaround (`<0`). | Алгебраическое условие #32; root finder проверял закрытые контрольные наборы, не эмпирические космологические параметры. |
| Плоская FLRW, обычная matter/radiation, `Λ≥0` | `F>0` при конечном `a>0`, `Hdot≤0`; регулярный конечный contraction→expansion bounce исключён в этом наборе. | Условный analytic no-go #32, не universal GR no-go. |
| #32 закрытый пример: `Ωr=.00009, Ωm=.3, ΩΛ=2, Ωk=−1.30009` | Локальные корни `a=.2571947827` turnaround и `.6464534366` bounce; между ними `F<0`, значит connected trajectory не проходит из одного корня к другому внутри этого решения. | Проверено численно на двух сетках и аналитическим `F`/`Hdot`; не создано из shell/black-hole data. |
| Israel root: unsquared junction + `ε±` orientation, `W≥0`, `R>0`, `σ>0` | Исключает ложные ветви после squaring. `ε+<0` указывает normal orientation/throat-like side, но не само по себе глобальную topology или causal separation. | Локально проверено #33–35 для указанных параметров. |
| #33 default `Hv=.0716 Gyr⁻¹, m=s=.2` | Schwarzschild horizon `x=2m=.4`, dS static horizon `x=1`; roots `.6553745606` ordinary turnaround `(+,+)` и `.8323520080` throat-oriented local shell bounce `(-,-)`; `W<0` между ними. | Условие локальной shell-модели, не root самого #32 FLRW. Глобальное родительство/дочерность неизвестны. |
| Canonical scalar / flat GR FLRW | `ρ+p=φdot²≥0`, `Hdot=−4πGφdot²≤0`. | Conditional #36. Потенциал произволен в этом argument, пока минимальное canonical action и flat GR FLRW сохранены. |
| Simple minimally coupled `P(X,φ)` with `X>0` in local high-frequency principal limit | NEC violation needs `P_X<0`; if `D=P_X+2XP_XX>0`, then `c_s²=P_X/D<0`; if `D<0`, scalar has ghost. At `D=0` principal description degenerates. | Conditional #36; not a full curvature-perturbation analysis and not a no-go for all modified gravity. |
| Positive constant shell tension `σ` with `p=−σ`, no bulk energy flux | Surface NEC saturates (`σ+p=0`), WEC holds for `σ≥0`; does not establish smooth formation. | Exact wall stress condition #33, not transferred to scalar-field model. |
| Isolated time relabeling | Monotone `K(a)` changes assigned time coordinate only; scalar/geometric invariants at the same events are unchanged absent a physical coupling. | No-coupling #31, residual in identical daughter observables zero. It does not constrain models with an independently defined interaction. |

## Toy values, physical constraints, and unknowns

- **Reference cosmology, not a fit:** #31 uses `Ωm=.3, Ωr=.00009, ΩΛ=.69991`, `H0=.0716 Gyr⁻¹`. It supplies a reproducible baseline only.
- **Illustrative H1 clock:** `K0=10⁹ daughter-year/parent-second`. It produces a dimensionally labelled conversion only conditional on an already specified `a_D(t_D)` and a physical `T_P` worldline. Neither is supplied by #38–40 or the spherical shell solvers.
- **Shell scan:** `m,s` samples documented in #33/#37 are finite solver scans. Root absence on a finite interval is not a global no-solution bound.
- **Potential scan:** `λ=1, δ=.02` and scalar amplitudes/radii are toy inputs; no particle-physics or black-hole observations calibrate them.
- **#38 coupling toy:** `alpha_ref,p=1/137`, `alpha_ref,d=1/142`, thresholds and beta coefficients are chosen examples; not measured daughter values or parent constraints.
- **No common admissible region yet:** #32 FLRW fluid bounce, #33 vacuum shell, #36 NEC violating toys, #38 law-running toy, and #39–40 scalar fields have distinct actions/stress tensors and sometimes different manifolds. Their parameters cannot be intersected into one “allowed H1 region” until a single covariant action and map of variables are derived.
- **Undetermined:** common-gravity coupling, transition/bounce density, conserved charge/energy crossing levels, relation of shell radius to `a_D`, and any universal parent/daughter clock ratio. Assigning numeric bounds to these now would invent a model.

The reusable equations and their provenance are indexed in [the mathematical registry](h1-v0.2-mathematical-registry.md). No parameter sweep or new numerical experiment was run for this dictionary.
