## Что исключено

- `src/`, `tests/`, `pyproject.toml`, `uv.lock`: исполняемый симулятор, тестовый код и настройки зависимостей не публикуются; старый solver — архивный и численно невалидированный.
- `.git/`: частная история и remotes не переносятся. Экспорт не инициализирован как Git-репозиторий.
- `.venv/`, `.uv-cache/`, `.pytest-*`, `.pytest_cache/`, runtime DB/cache и прочие локальные артефакты: не научные публикационные материалы.
- `.ai-bridge-project.json`, `PROJECT_CONTEXT.md`, private worker/bridge logs и исходный root `README.md`: содержат проектный контекст/непубликационную навигацию; вместо root README создан отдельный публичный вводный документ.
- Исходные `LICENSE` и `CONTRIBUTING.md`: отдельное решение о лицензии для публичного набора не принято; лицензия не назначается автоматически.
- В `docs/` не обнаружено не-Markdown figure/plot/CSV/JSON файлов. Сырые артефакты из тестовых временных каталогов не отбирались и не публиковались.
- Полные тексты сторонних статей и чужие данные не включены. Оставлены ссылки DOI/arXiv.

## Санитизация и известные пробелы

- В просмотренных документах не обнаружены совпадения с распространёнными шаблонами GitHub PAT, AWS access key или PEM private key; обнаружены ноль совпадений с общими словами credential/token/password/API key, служебными Telegram/webhook/callback маркерами и частными GitHub issue URL. Это ограниченная статическая проверка, не математическая гарантия отсутствия секретов.
- В одном отчёте обнаружен абсолютный Windows path; в экспортной копии он заменён. Ссылки формата `Issue #...` и служебные идентификаторы обсуждений заменены описательными названиями. Экспериментальные обозначения #31–41F сохранены.
- В исходных документах найдены только внешние URL доменов `doi.org` и `arxiv.org`; они сохранены. Приватных GitHub issue URLs не найдено.
- `docs/experiment-equations-cross-audit.md` включён как существующий cross-audit; его связь с отдельным историческим номером не подтверждена и не утверждается.
- Исторические результаты содержат несогласованные или невалидированные численные схемы, включая mass ledger/constraint discrepancies. Они оставлены как отчёты с собственными оговорками, а не пересказаны как подтверждение H1.

Публичная видимость, владелец, URL, ветка и commit SHA должны быть добавлены только после успешной публикации и независимой проверки GitHub API.
